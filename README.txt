CubeLab — автономный тренажёр CFOP
Содержит 57 OLL и 21 PLL алгоритм, генератор ходовых скремблов 2x2–7x7, поиск, статусы обучения, экспорт/импорт прогресса.
Запуск: откройте index.html в браузере. Для установки PWA и гарантированного кэширования офлайн откройте папку через локальный HTTP-сервер (например, python -m http.server 8000), затем посетите http://localhost:8000 и установите приложение.
После первого открытия через HTTP Service Worker сохраняет файлы для автономной работы.
ВАЖНО: текущая сетка 3×3 в карточке — условная иллюстрация, не точная распознавательная схема конкретного OLL/PLL. Алгоритмы взяты из открытого проекта CFOP Tracker (MIT); см. LICENSE.
